DoH Latency Tester

Measure network latency and DNS resolution of DoH servers

Offline

How to use

  1. Click Start Test to measure latency of the built-in list of 200+ public DoH resolvers.
  2. Optionally open Settings to load your own servers.txt (one DoH URL per line) or choose a domain to validate DNS resolution against.
  3. Results are sorted by latency: 🟢 ≤ 50 ms, 🟡 ≤ 150 ms, 🔴 > 150 ms. Hover over a value to see the DNS status. Use the chips above the list to filter results.
  4. Use Export CSV to save the results, or Share where your browser supports it.
  5. Install the app (button in the top bar, or your browser's install option) to use it offline.

Everything runs locally in your browser — no data is sent anywhere. Source code and documentation: github.com/viktor45/race
